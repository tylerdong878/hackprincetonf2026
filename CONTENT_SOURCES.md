# Content sources

Every real item used in the five seed Dailies (2026-11-13 to 2026-11-17) and the Con-the-Con Fool Deck.
The material bank lives in [`scripts/build_daily_cases.py`](scripts/build_daily_cases.py) (`BANK`); the files in
`data/cases/2026-11-1*-daily-*/` and `data/fool_deck/` are generated from it.

**How it was verified.** On 2026-11-14 each source page was fetched with a plain HTTP client (no login, no
paywall, no blocked site: every site allowed the fetch and its robots.txt allows article pages). Each excerpt was
copied from the fetched text and checked word for word. The check ignores only typography: curly vs. straight
quotes, dash style and whitespace. `uv run python scripts/build_daily_cases.py --verify` re-fetches every page and
re-checks all excerpts. Last run, 2026-11-14: **78/78 excerpts from 18 pages matched**, and the 4 local FRED CSVs
matched the live data. Dates come from each page's `datePublished` metadata, or the press-release dateline.

**Re-run before judging:** `uv run python scripts/build_daily_cases.py --verify`. If a page has been edited since,
it prints `XX`, and that item must be fixed or dropped.

**Licensing.** New Jersey Monitor is CC BY-NC-ND 4.0, so we use short attributed excerpts with a link and never a
doctored version under its name. NPR, New Jersey 101.5 and WHYY are used the same way: short attributed excerpts
with a link. EIA and BLS data are U.S. government works.
